CoinSwitch Scalping Lab

A local trading research application for repeatable replay and read-only market-feed PAPER sessions, with durable ledgers and a dashboard for inspecting decisions.

Astrology Evidence

A working local application that keeps chart calculations, retrieved source passages and AI interpretations distinct, so readers can inspect the reasoning and its limits.

Architecture & readiness +

Jinja2 server UI with small JavaScript enhancements → FastAPI → PostgreSQL for anonymous workspaces, profiles and application state. Chart calculations stay separate from rights-gated source retrieval through Qdrant and a bounded LangGraph reading workflow. Privacy jobs handle retention and deletion; AI and embeddings are disabled by default.

The local app uses synthetic data and is not cleared for real-user production. Licensed sources, chart validation, provider review, expert quality evaluation and operational recovery checks remain release gates. Citations do not establish astrology's predictive validity. The public guide documents the app; it does not host it. Explore the source ↗
